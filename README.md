# **一个基于 Python、OpenCV 和 PyQt5 开发的 AI 人像美颜桌面应用，支持一键实现瘦脸、磨皮、美白、锐化、亮眼、红唇等多种美颜效果，提供直观的交互界面和实时预览对比功能。**

#### **✨ 功能特性**

\- 人脸自动检测：基于 dlib 的 68 点人脸关键点检测，精准定位五官与面部轮廓

\- 一键美颜效果：

&#x20; - ✨ 磨皮：结合高斯模糊与双边滤波，实现自然平滑的皮肤效果

&#x20; - 🌟 美白/提亮：针对皮肤分区进行 HSV 空间亮度与饱和度调整

&#x20; - 👀 亮眼/锐化：对眼部等关键区域进行细节增强，让眼睛更有神

&#x20; - 👄 红唇：针对性提升唇部色彩饱和度，打造自然唇妆效果

&#x20; - 📸 整体锐化：USM 锐化算法，提升照片整体清晰度

&#x20; - 📐 瘦脸：基于局部平移扭曲算法，实现自然的脸型优化

\- 交互体验优化：

&#x20; - 支持滑块调节美颜强度，实时预览效果

&#x20; - 提供「撤销/确认/重置」操作，方便对比调整

&#x20; - 支持原图与效果图对比查看，可保存对比图

&#x20; - 支持保存单张美颜后的图片

\- 跨平台兼容：基于 PyQt5 开发，可在 Windows/Linux 平台运行



#### 🛠️ **环境依赖**

\- Python 3.7+

\- 依赖库：

&#x20; ```bash

&#x20; pip install opencv-python dlib numpy imutils pyqt5 qdarkstyle

&#x20; ```

\- 额外文件：dlib 人脸关键点预测模型 `shape\_predictor\_68\_face\_landmarks.dat`

&#x20; - 下载地址：\[dlib 官方文件](http://dlib.net/files/shape\_predictor\_68\_face\_landmarks.dat.bz2)

&#x20; - 解压后将 `.dat` 文件放入项目的 `./data` 目录下

#### **📖 使用说明**

1\. 打开图片：点击「打开文件」，选择本地图片（支持 `png/jpg/bmp` 格式）

2\. 调节美颜效果：

&#x20;  - 点击对应功能按钮（如「美白」「磨皮」「瘦脸」），拖动滑块调节强度

&#x20;  - 调节过程中可实时查看效果

3\. 操作管理：

&#x20;  -「确认更改」：保存当前调节效果

&#x20;  -「撤销更改」：回到上一步操作

&#x20;  -「还原」：恢复到原始图片

4\. 查看与保存：

&#x20;  -「查看对比」：弹出窗口对比原图与美颜效果

&#x20;  -「保存」：保存当前美颜后的图片

&#x20;  -「保存对比图」：保存原图与美颜效果的拼接对比图



#### **💡 核心算法说明**

\- 人脸关键点检测：使用 dlib 提供的 68 点特征检测器，精准定位面部轮廓与五官位置

\- 瘦脸算法：基于局部平移扭曲（Local Translation Warp），通过计算关键点距离，实现自然的脸型收缩

\- 磨皮算法：结合双边滤波（保边平滑）与高斯模糊，在保留五官边缘的同时实现皮肤柔化

\- 美白/提亮：在 HSV 色彩空间中调整亮度（V通道）与饱和度（S通道），针对性优化肤色与唇色

\- 锐化算法：使用 USM（Unsharp Mask）锐化和自定义卷积核，增强图像细节与清晰度



#### **📌 注意事项**

1\. 首次运行时，若未检测到模型文件，需手动选择 `shape\_predictor\_68\_face\_landmarks.dat` 文件

2\. 建议使用正面、光线充足的人像照片，人脸过小或角度过大可能影响检测效果

3\. 调节美颜强度时建议循序渐进，避免过度调整导致效果失真

4\. 程序运行时若出现卡顿，可尝试减小输入图片尺寸
